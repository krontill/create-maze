Maze generation algorithms rendered as a CSS Grid.  View algorithm comparison →

Depth-First Search

Iterative recursive backtracker. Produces long, winding corridors with few dead ends. O(W×H) time and space.

Prim's Algorithm

Randomised Prim's — grows from a seed cell by randomly picking frontier walls. Produces more branchy, uniform mazes. O(W×H) average.

Kruskal's Algorithm

Randomised Kruskal's — shuffles all internal walls and merges disjoint sets. Produces uniformly random spanning trees. O(W×H · α(W×H)) time.

Binary Tree

Processes every cell once, carving north or east at random. Produces a strong diagonal bias toward the top-right. O(W×H) time, O(1) extra space.

Wilson's Algorithm

Loop-erased random walks grow the maze one path at a time. Produces a provably uniform spanning tree — every perfect maze is equally likely. O(W×H·log(W×H)) expected time.

Aldous-Broder

Uniform random walk over the grid — walls are removed only on the first visit to each cell. Produces a uniform spanning tree with no bias. Simple but slow: O(W×H·log(W×H)) expected time.

Eller's Algorithm

Builds the maze one row at a time using disjoint sets. Merges adjacent cells of different sets horizontally, then carves at least one downward passage per set. Produces a perfect maze in O(W×H) time with only O(W) space.

Sidewinder

Processes each row left to right, collecting cells into a run. Each step either extends the run east or closes it by carving north from a random run member. The top row is always open east. O(W×H) time, O(W) space.

Hunt-and-Kill

Alternates between a random walk (kill phase) that carves into unvisited neighbours, and a row-by-row scan (hunt phase) that finds the next unvisited cell adjacent to the maze. Produces mazes with long, winding corridors. O((W×H)²) worst-case time, O(W×H) space.

Recursive Division

Starts with a fully open grid and repeatedly bisects chambers with walls, leaving exactly one passage per wall. Produces mazes with long straight corridors and clearly visible rectangular regions. O(W×H) time, O(W+H) stack space.

Growing Tree

Meta-algorithm that blends DFS and Prim's by choosing the newest cell (50 %) or a random cell (50 %) from an active list. Produces passages that are longer than Prim's but more branched than DFS. O(W×H) time and space.

Houston's

Combines Aldous-Broder and Wilson's for speed and uniformity. Seeds ~40 % of cells via a fast random walk (Aldous-Broder), then finishes with loop-erased random walks (Wilson's). Produces a uniformly random spanning tree. O(W×H·log(W×H)) expected time.
