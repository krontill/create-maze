maze-builder

All three generation algorithms — DFS, Prim's, Kruskal's — rendered as a CSS Grid.

Depth-First Search

Iterative recursive backtracker. Produces long, winding corridors with few dead ends. O(W×H) time and space.

Prim's Algorithm

Randomised Prim's — grows from a seed cell by randomly picking frontier walls. Produces more branchy, uniform mazes. O(W×H) average.

Kruskal's Algorithm

Randomised Kruskal's — shuffles all internal walls and merges disjoint sets. Produces uniformly random spanning trees. O(W×H · α(W×H)) time.
